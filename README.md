# 🎤 Voice Game - Unity

> **목소리로 조종하라. 침묵은 곧 죽음이다.**

**Voice Game**은 플레이어의 **목소리로 캐릭터를 조작**하는 실험적인 1인칭/3인칭 러너 게임입니다. 마이크를 통해 인식된 **소리의 크기**에 따라 캐릭터가 이동하며, 끊임없이 이어지는 코스를 회피하고 살아남는 것이 목표입니다.

---

## 🕹️ 게임 특징

- 🎙️ **소리 기반 조작 시스템**  
  키보드 대신 **마이크 입력으로만 조작**합니다. 소리의 크기가 곧 속도입니다.

- 🏃 **무한 진행형 러너 시스템**  
  죽을 때까지 계속 달립니다. 기록을 갱신하세요!

- 🧠 **몰입도 높은 인터랙션**  
  목소리로 플레이하는 완전히 새로운 조작 방식의 게임 경험.

---

## 🎧 플레이 방법

| 동작 | 설명 |
|------|------|
| 이동 | 마이크로 소리 내기 (예: “아아아!”, “으아아아!”) |
| 멈춤 | 조용히 있기 (무음) |
| 목표 | 장애물을 피하고, 가능한 오래 생존하기 |
